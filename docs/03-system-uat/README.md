# Bukti Uji Sistem & UAT (03-system-uat)

Folder ini menyimpan dokumentasi dan rekaman hasil pengujian sistem end-to-end (Playwright) serta hasil User Acceptance Testing (UAT):
- Skenario alur pasien (login -> reservasi janji -> nomor antrian).
- Skenario alur admin (buat jadwal -> panggil antrian -> kelola kontrol).
- Hasil evaluasi kuesioner System Usability Scale (SUS).
