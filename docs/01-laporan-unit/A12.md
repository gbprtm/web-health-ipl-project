# Laporan Bukti Tugas A12: Indeks, Constraint, dan Aturan Append-Only

## Deskripsi
Implementasi indeks parsial, batasan unik, dan aturan integritas append-only pada skema Drizzle ORM sesuai PRD §6 dan §4.3:
1. **Indeks Unik Parsial Satu Janji Aktif per Slot**: `janji_slot_aktif_unique_idx` pada tabel `janji` dengan predikat `WHERE status = 'aktif'`.
2. **Indeks Unik Nomor Antrian per Hari**: `tiket_antrian_tanggal_nomor_final_unique_idx` pada tabel `tiket_antrian` dengan predikat `WHERE nomor_antrian_final IS NOT NULL`.
3. **Indeks Unik Catatan Minum Obat**: `catatan_minum_obat_unique_idx` pada kolom gabungan `(pasien_id, obat_id, tanggal)`.
4. **Append-Only Audit Log**: Tabel `audit_log` dan `log_aktivitas` tidak memiliki kolom `updated_at`.
