## Kriteria Terima

1. Dua janji aktif pada slot sama ditolak database.
2. Uji constraint lulus.

Turunan yang diminta `rencana-agen.md`:

- indeks unik parsial satu janji aktif per slot (`janji_slot_aktif_unique_idx`);
- unik nomor antrian final per tanggal (`tiket_antrian_tanggal_nomor_final_unique_idx`);
- unik catatan minum per pasien, obat, tanggal (`catatan_minum_obat_unique_idx`);
- tidak ada kolom `updated_at` pada `audit_log` dan `log_aktivitas`.

### 2. Migrasi yang menegakkan aturan

`src/db/migrations/0003_keen_chamber.sql`:

```sql
CREATE UNIQUE INDEX "janji_slot_aktif_unique_idx" ON "janji" USING btree ("slot_id")
  WHERE "janji"."status" = 'aktif';
CREATE UNIQUE INDEX "tiket_antrian_tanggal_nomor_final_unique_idx"
  ON "tiket_antrian" USING btree ("tanggal","nomor_antrian_final")
  WHERE "tiket_antrian"."nomor_antrian_final" IS NOT NULL;
```

`catatan_minum_obat_unique_idx` sudah dibuat pada migrasi `0002` dan diuji
lewat metadata Drizzle di `constraint.test.ts`.

### 4. Append-only

`audit_log` tidak memiliki `updated_at` (diuji di `constraint.test.ts`).
`log_aktivitas` diverifikasi lewat bentuk tabel, belum lewat percobaan UPDATE
yang ditolak — aturan append-only di tingkat database belum ada trigger.
