## Kriteria Terima (Acceptance Criteria)

1. **Migrasi Berhasil**:
   - Skrip `npm run db:generate` menghasilkan berkas migrasi `0001_spooky_ken_ellis.sql` tanpa galat.
   - Skrip `npm run db:migrate` berhasil menerapkan migrasi ke database PostgreSQL Neon (`neondb`).
2. **Semua Entitas PRD §6 Terwakili**:
   - `dokter`: Data master dokter (spesialisasi, izin praktik, status aktif) tanpa kredensial login.
   - `slot`: Jadwal praktik dokter (tanggal, jam mulai, jam selesai, kuota, status tersedia, TTL kunci slot).
   - `janji`: Relasi janji temu pasien dengan dokter dan slot, keluhan, dan catatan pembatalan.
   - `usulan_perubahan`: Entitas usulan perubahan jadwal dari admin dengan status, batas waktu jawab, dan TTL kunci slot.
   - `notifikasi`: Notifikasi pasien dan staf klinik dengan jenis, status dibaca, dan payload data terkait.
   - `audit_log`: Pencatatan log aktivitas admin yang bersifat append-only (pelaku, aksi, objek, nilai sebelum/sesudah, alasan).
   - `aturan_kontrol`: Aturan berobat rutin berulang per 7/14/30 hari dengan anchor tanggal asli untuk mencegah drift tanggal.
3. **Siklus Status Janji Sesuai PRD §3.4**:
   - Enum PostgreSQL `status_janji` bernilai: `aktif`, `perubahan_diusulkan`, `dibatalkan`, `selesai`, `tidak_hadir`.
