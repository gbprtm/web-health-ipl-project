## Kriteria Terima (Acceptance Criteria)

1. **`npm run db:generate` dan `npm run db:migrate` berhasil**:
   - Skrip `db:generate` membaca `drizzle.config.ts` dan menghasilkan artefak migrasi tanpa galat.
   - Skrip `db:migrate` menerapkan migrasi ke database Neon PostgreSQL target (`neondb`) dengan sukses (`migrations applied successfully!`).
2. **Koneksi ke Neon terbukti dari skrip sederhana**:
   - Pengujian kueri `SELECT NOW(), current_database()` melalui driver `postgres` dengan `DATABASE_URL` berhasil mengembalikan waktu server dan nama basis data aktif (`neondb`).
3. **Pola singleton client**:
   - `src/db/client.ts` mengimplementasikan singleton via `globalThis` untuk mencegah kehabisan koneksi pada lingkungan hot reload dan serverless.
