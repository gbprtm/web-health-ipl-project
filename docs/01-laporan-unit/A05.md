## Kriteria Terima (Acceptance Criteria)

1. **Migrasi membuat kedua tabel**:
   - Tabel `users` dan `sessions` berhasil didefinisikan dan diterapkan ke PostgreSQL Neon via migrasi `0000_faithful_ultimates.sql`.
   - Pengecekan `information_schema.tables` membuktikan kedua tabel aktif di schema `public`.
2. **Email duplikat ditolak database**:
   - Kolom `email` memiliki constraint `users_email_unique UNIQUE("email")`.
3. **Peran hanya boleh pasien atau admin**:
   - Kolom `role` menggunakan PostgreSQL ENUM `user_role` bernilai `('pasien', 'admin')` dengan nilai default `'pasien'`.
4. **Relasi Sessions & Users**:
   - Tabel `sessions` memiliki foreign key `user_id` yang mereferensikan `users.id` dengan opsi `ON DELETE CASCADE`.
