1. **`npm run dev` dapat berjalan pada port 3000**:

2. **`npm run build` sukses tanpa error**:
   - Eksekusi `npm run build` menghasilkan halaman statis tanpa galat lint maupun tipe data.
3. **TypeScript `strict` dan `noUncheckedIndexedAccess` aktif**:
   - `tsconfig.json` memiliki `strict: true` dan `noUncheckedIndexedAccess: true`.

## Rincian Perubahan

- `package.json` & `package-lock.json`: Dependensi Next.js, React, Tailwind CSS, TypeScript, dan ESLint.
- `tsconfig.json`: Konfigurasi TypeScript strict mode dengan path alias `@/*`.
- `next.config.ts`: Konfigurasi Next.js.
- `postcss.config.mjs` & `tailwind.config.ts`: Konfigurasi styling Tailwind CSS.
- `eslint.config.mjs`: Konfigurasi linting ESLint flat config.
- `src/app/layout.tsx`, `src/app/page.tsx`, `src/app/globals.css`: Halaman utama dan tata letak dasar Next.js App Router.
