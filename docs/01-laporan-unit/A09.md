# Bukti Tugas A09: CI dan Deploy Skeleton

- **ID Tugas**: A09
- **Fase**: F0 (Fondasi)
- **Tanggal**: 2026-10-28
- **Status**: done

## Kriteria Terima (Acceptance Criteria)

1. **Workflow CI GitHub Actions**:
   - Berkas `.github/workflows/ci.yml` dikonfigurasi untuk memicu verifikasi otomatis pada setiap `push` dan `pull_request` ke cabang `main` dan `master`.
   - Menjalankan 4 tahapan verifikasi kualitas:
     - `npm run lint` (ESLint)
     - `npm run typecheck` (TypeScript strict)
     - `npm test` (Unit test Vitest)
     - `npm run build` (Next.js production build)
2. **Koneksi dan Integrasi Vercel (Rp0)**:
   - Prosedur deployment zero-configuration terdokumentasi di `README.md`.
   - Menggunakan integrasi Git di Vercel Dashboard tanpa ketergantungan pada Vercel CLI.
   - Variabel lingkungan terdefinisi pada Vercel project settings (`DATABASE_URL`, `DATABASE_URL_UNPOOLED`, `SESSION_SECRET`, `APP_URL`).
3. **Penyelesaian Gerbang G0 (Fase Fondasi)**:
   - Seluruh fondasi A01 s.d. A09 tuntas.
   - Kode aplikasi siap di-deploy sebagai skeleton hidup dengan seluruh suite pengujian hijau.
