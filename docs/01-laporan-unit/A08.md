# Bukti Tugas A08: Runner Vitest dan Playwright

- **ID Tugas**: A08
- **Fase**: F0 (Fondasi)
- **Tanggal**: 2026-10-28
- **Status**: done

## Kriteria Terima (Acceptance Criteria)

1. **Konfigurasi Vitest dengan jsdom dan alias tsconfig**:
   - Berkas `vitest.config.ts` telah dikonfigurasi menggunakan plugin `@vitejs/plugin-react` dan `vite-tsconfig-paths` dengan environment `jsdom`.
   - Setup berkas `tests/setup.ts` mengonfigurasi `@testing-library/jest-dom/vitest` serta penanganan realm TextEncoder/Uint8Array untuk modul kriptografi di jsdom.
2. **Konfigurasi Playwright Chromium & WebServer**:
   - Berkas `playwright.config.ts` dikonfigurasi menggunakan browser Chromium bawaan sistem (channel: `chrome`) sehingga menghemat ruang penyimpanan dan tidak membutuhkan unduhan biner Chromium terpisah (~200 MB).
   - Menjalankan `webServer` Next.js otomatis via `npm run dev` pada port 3000.
3. **Skrip NPM**:
   - `npm test`: Menjalankan suite Vitest (`vitest run`).
   - `npm run test:e2e`: Menjalankan suite Playwright (`playwright test`).
   - `npm run typecheck`: Menjalankan pemeriksaan tipe TypeScript (`tsc --noEmit`).
   - `npm run lint`: Menjalankan ESLint (`eslint`).
4. **Contoh Pengujian**:
   - Unit test contoh: `tests/unit/example.test.ts` (menguji lingkungan dasar jsdom).
   - E2E test contoh: `tests/e2e/example.spec.ts` (menguji keterbacaan halaman `/` dan `/masuk`).
