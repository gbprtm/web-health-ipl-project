# Bukti Tugas A07: Format Respons API Baku

- **ID Tugas**: A07
- **Fase**: F0 (Fondasi)
- **Tanggal**: 2026-10-28
- **Status**: done

## Kriteria Terima (Acceptance Criteria)

1. **Bentuk Sukses `{ data }` dan Galat `{ error: { code, message, fields? } }`**:
   - `src/lib/http.ts` menyediakan helper `successResponse<T>(data)` (200 OK) dan `createdResponse<T>(data)` (201 Created) yang membungkus data dalam properti `{ data: T }`.
   - `src/lib/http.ts` menyediakan `errorResponse()` yang menghasilkan JSON terstruktur `{ error: { code, message, fields? } }`.
2. **Pemetaan Galat Zod ke 422**:
   - `src/lib/api.ts` menyediakan `mapZodErrorToFields()` dan `formatZodError()` untuk memetakan `ZodError` secara otomatis ke HTTP 422 Unprocessable Entity.
   - Pesan galat validasi menampilkan field yang salah dalam bentuk dictionary `Record<string, string[]>`.
3. **Helper Galat HTTP Baku**:
   - Helper 401 Unauthorized (`unauthorizedResponse()`).
   - Helper 403 Forbidden (`forbiddenResponse()`).
   - Helper 404 Not Found (`notFoundResponse()`).
   - Helper 409 Conflict (`conflictResponse()`).
   - Helper 422 Unprocessable Entity (`unprocessableEntityResponse()`).
   - Helper 500 Internal Server Error (`internalErrorResponse()`).
4. **Penanganan Galat Terpadu**:
   - Fungsi `handleApiError()` memetakan kelas galat internal (`ZodError`, `ValidationError`, `AuthenticationError`, `AuthorizationError`, `NotFoundError`, `ConflictError`, `AppError`) ke respons HTTP yang sesuai.
   - Fungsi `withErrorHandler()` bertindak sebagai higher-order function untuk Route Handler API Next.js agar tidak ada galat yang lolos tanpa format baku.
