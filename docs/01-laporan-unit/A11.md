# Bukti Tugas A11: Skema Domain Pasien

- **ID Tugas**: A11
- **Fase**: F1 (Data)
- **Tanggal**: 2026-10-28
- **Status**: done

## Kriteria Terima (Acceptance Criteria)

1. **Migrasi Berhasil**:
   - Skrip `npm run db:generate` menghasilkan berkas migrasi `0002_remarkable_daimon_hellstrom.sql` tanpa galat.
   - Skrip `npm run db:migrate` berhasil menerapkan migrasi ke database PostgreSQL Neon (`neondb`), mencakup 9 tabel baru domain pasien sehingga total tabel sistem menjadi 18 tabel.
2. **Nomor Estimasi Tidak Disimpan sebagai Kolom (Turunan)**:
   - Tabel `tiket_antrian` diverifikasi hanya menyimpan kolom `nomor_antrian_final` yang diterbitkan saat check-in.
   - Nomor estimasi antrian dihitung secara dinamis saat runtime berdasarkan urutan slot dan rata-rata durasi periksa, sesuai ketetapan PRD §3.5 & §6.
3. **Integritas & Constraint Domain Pasien (PRD §6)**:
   - Tabel `catatan_minum_obat` memiliki constraint indeks unik gabungan `(pasien_id, obat_id, tanggal)` (`catatan_minum_obat_unique_idx`) untuk mencegah duplikasi penandaan minum obat harian.
   - Tabel `log_aktivitas` dirancang append-only tanpa timestamp pembaruan untuk audit jejak aktivitas akun pasien (FR-14).
   - Tabel `konten_statis` mencakup kolom `slug`, `kategori`, `kondisi_terkait`, `url_sumber`, dan `tanggal_pengambilan` (FR-06).
   - Siklus status antrian memakai enum `status_antrian` (`belum_check_in`, `menunggu`, `diperiksa`, `selesai`, `tidak_hadir`).
