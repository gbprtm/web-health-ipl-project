# Laporan Bukti Tugas A13: Seed Admin Individual dan Data Fiktif

## Deskripsi
Implementasi data seed untuk kebutuhan demo dan pengujian aplikasi sesuai PRD §4.2 Privacy:
1. **Dua Akun Admin Terpisah**:
   - `admin1@klinik-sehat.local` (Staf Admin Satu (Fiktif))
   - `admin2@klinik-sehat.local` (Staf Admin Dua (Fiktif))
   - Menggunakan bcrypt hash kata sandi terverifikasi (`AdminKlinik2026!`).
2. **Master Dokter & Slot Contoh**:
   - Dokter spesialis berizin fiktif (`SIP-FIKTIF-001/2026`, dll.).
   - Slot praktik dokter dengan tanggal, jam mulai, dan kuota pasien.
3. **Pasien & Riwayat Fiktif**:
   - Akun pasien fiktif dengan NIK dummy 16-digit (`3171000000000001`, dll.).
   - Catatan profil kesehatan (hipertensi) dan log kebiasaan (air minum & tidur).
4. **Idempotensi**:
   - Skrip `npm run db:seed` aman dijalankan berulang kali tanpa membuat duplikasi data atau memicu pelanggaran constraint unik.
5. **Kepatuhan Ruang Lingkup**:
   - Tidak membuat `src/db/seed/konten.ts` karena berkas tersebut dialokasikan untuk tugas B13.
